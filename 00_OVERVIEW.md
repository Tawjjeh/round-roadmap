# Open Source Contributor Roadmap (3 Months / 6 Sprints)

## Overview

A structured **3-month (6-sprint)** roadmap designed to guide developers from fundamental Git workflows to confident open source contributors.

Each 2-week sprint combines:
- **Technical Topic**: Practical software engineering topics (.NET, Git, Code Quality, Testing, APIs, Error Handling).
- **Open Source Workflow Topic**: Navigating real-world repositories, contributing guidelines, licensing, code reviews, and bug reporting.
- **Problem Solving Track**: 3 coding challenges per sprint to build analytical and algorithmic problem-solving skills.
- **Resources & References**: Curated links and reference materials relevant to the topics covered.

## Monthly Summary

### Month 1: Setup & Foundations (Sprints 1–2)
Establish solid Git branching habits, understand project layouts, configure formatting standards, and learn how to triage beginner-friendly issues.

### Month 2: Quality & Validation (Sprints 3–4)
Write defensive code with input validation and configuration management, understand open source licenses, and master unit testing and pull request etiquette.

### Month 3: Data Contracts & Resilience (Sprints 5–6)
Decouple APIs using DTOs and serialization, author high-quality project documentation, implement centralized error handling and logging, and submit reproducible bug reports.
