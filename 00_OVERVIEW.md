# Round Roadmap (3 Months / 6 Sprints)

## Overview

A structured **3-month (6-sprint)** program to prepare developers for open source contributions.

Each sprint (2 weeks) includes:
- **Open Source Session**
- **Problem Solving Session**
- **System Design Book**
- **Sprint Closing**

---

## Sprint Tasks (Fixed per Sprint)

| Task | Count |
| :--- | :---: |
| Problem Solving | 5 Problems |
| Pull Requests | 5 PRs |
| Issues | 1 Issue |
| Technical Topic Note | 1 |
